这个页面在做什么
  • 每一步都由后端从头回放整段历史、经过 O5ProtocolFsm.advance 校验；合法集合只有一个具体 token 时自动填上，直到出现多个选择。
  • 普通 token 不展开具体 id，统一为 ‹普通 token›（= 整个普通词表）。即使它是唯一选项也不会自动填，因为具体哪个词仍要模型选。
  • system prompt 整段、以及每个 unit 的 user_video / user_audio / input_event 整段，各抽象成一次 prefill，只管协议合法性不管语义。
  • <|non_spoken_budget_reached|> 由推理框架写入；状态机只告诉你「此处框架可以写」，点不点由你决定（budget ≥ 1，所以 slot 首步不提供）。
  • 数字键 1–9 选选项，Backspace 撤销。点时间线上任何一个蓝色 / 橙色块，回到那一步重新选。
