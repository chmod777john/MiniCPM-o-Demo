端点

一个端点 = 一个对外接入地址 + 背后的一组 Worker；会话按顺序分给空闲 Worker，忙不过来就排队
＋ 新建端点

端点名会出现在接入地址里：只能用小写字母、数字、连字符，以字母或数字开头，最多 40 位。

Worker 模板

一个模板 = 加载哪个 checkpoint + 一组 Session 默认参数；添加 / 扩容 Worker 都从模板起
＋ 新建 / 编辑模板

下面几项只是默认值：调用方创建 Session 时没传才用它们，传了就以调用方为准。

同名模板保存即覆盖；已起的 Worker 不受影响（新默认值对之后起的 Worker 生效）。
